# Merge: `.gitignore`

The three site-root discovery files and the dev fixtures are generated on every
build (`prebuild`) and must not be committed. Append this block to the end of
the project's `.gitignore`:

```gitignore
# agent content layer — generated on build, not committed
public/sitemap-agents.xml
public/llms.txt
public/robots.txt
content/agents/__fixture-*.md
```

## Notes

- `public/robots.txt` is now generated by `scripts/generate-robots-txt.ts`. If
  the project has a committed `public/robots.txt`, delete it from git
  (`git rm --cached public/robots.txt`) after confirming the generator's output
  covers its rules — the generator emits a permissive policy plus `Sitemap:`
  lines for both the agent sitemap and the existing Sanity sitemap. If the
  committed file has project-specific `Disallow` rules, port them into the
  generator call site first and flag the difference to the developer.
- Real agent content (`content/agents/*.md` produced by backfill or
  PublishForge) IS committed — only `__fixture-*` files are ignored.
